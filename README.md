# Junhao Ye · Academic Homepage

This is the local academic homepage for Junhao Ye (叶俊豪). It keeps the original template's restrained typography, dotted background, section dividers, and compact publication layout while replacing the template owner's content with Junhao's verified profile.

## Preview

From `D:\个人主页`:

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

Open <http://127.0.0.1:4173/>. This previews the page locally; it does not publish it.

- `index.html` — Junhao's homepage and all outgoing academic links.
- `style.css` — original academic template stylesheet.
- `home.css` — page-specific styles for research cards, publication metadata, achievement cards, media features, and responsive layout.
- `home.js` — News expansion and one-click BibTeX copying.
- `assets/junhao-ye.jpg` — portrait from the public research group page.
- Framework figure assets — cropped from Junhao’s local camera-ready papers.
- University emblem assets — sourced from official university visual-identity pages.
- Competition certificate assets — originals from Junhao’s Excellent Star of Liyuan PPT and the undergraduate awards portfolio; the 2022 Guangdong certificate was rendered from the portfolio PDF.
- Volunteer photograph — selected from Junhao’s Excellent Star of Liyuan presentation.
- Media feature covers — official public article covers, stored locally to avoid hotlink failures.
- `assets/media/liyuan-excellence-star.mp4` — optimized 720p web version of the supplied two-minute profile film.
- `reference-index.html` and `reference-style.css` — saved template reference.

The template's `scripts/build-local-clone.mjs` recreates the *original* template owner’s page. Do not run it when editing this homepage.
